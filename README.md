# EQUA AI — sitio web

Prototipo académico basado en la propuesta de EQUA AI: conectar talentos estudiantiles para desarrollar soluciones ambientales en Junín.

## Archivos
- `index.html`: página web completa y responsive.
- `robots.txt`: preparado para buscadores.
- `sitemap.xml`: mapa del sitio para Google.
- `README.md`: instrucciones.

## Importante
La demo es un prototipo front-end. El cuestionario, las coincidencias, el asistente de IA, cuentas de estudiantes, almacenamiento de proyectos y funciones institucionales todavía requerirían un backend/base de datos y controles de privacidad antes de usarse con estudiantes reales.

## Publicación
Una opción sencilla para un proyecto escolar es GitHub Pages. Después de publicar, reemplaza `TU-DOMINIO-AQUI` en `index.html`, `robots.txt` y `sitemap.xml` por la dirección real del sitio.
